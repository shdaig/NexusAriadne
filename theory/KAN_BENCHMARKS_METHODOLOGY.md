# Методология экспериментов в статье KAN (arXiv:2404.19756)

## Общая структура демонстрации производительности

Статья KAN (Liu et al., 2024) организует экспериментальную часть в две категории:

1. **Математика и физика** (раздел 3) — синтетические задачи с известным ответом
2. **Наука** (раздел 4) — реальные приложения, где KAN демонстрирует интерпретируемость

Ключевой принцип: **Pareto-оптимальность**, а не сравнение при фиксированном бюджете параметров. Авторы строят кривую «качество vs. размер модели» и показывают, что KAN находится выше MLP на этой границе.

---

## Метрика сравнения: Pareto-граница

**Зачем Pareto, а не фиксированная архитектура?**

KAN и MLP нельзя корректно сравнивать при одинаковом числе параметров, потому что:
- KAN масштабирует точность через число узлов сетки `G` (spline grid), не только через ширину/глубину
- MLP масштабирует через ширину/глубину
- Оптимальные архитектуры для каждой парадигмы различаются

**Построение Pareto-границы:**
- Ось X: `log(количество параметров)`
- Ось Y: `log(RMSE)` на тестовой выборке
- Каждая точка — одна архитектура (конкретная ширина, глубина, `G`)
- KAN побеждает, если его Pareto-граница **левее и ниже** MLP

## Раздел 3.1 — Игрушечные наборы данных (Toy Datasets)

### Тестируемые функции

5 математических функций:

| Функция | Пространство |
|---------|-------------|
| `f(x,y) = exp(sin(πx) + y²)` | `[-1,1]²` |
| `f(x,y) = xy` | `[-1,1]²` |
| `f(x,y,z,w) = exp(sin(πx) + y²) + exp(sin(πz) + w²)` | `[-1,1]⁴` |
| `f(x,y,z,w) = exp(sin(π(x+y)) + (z+w)²)` | `[-1,1]⁴` |
| `f(x₁,...,x₁₀₀) = Σ sin(xᵢ)` | `[-1,1]¹⁰⁰` |

### Архитектура KAN

- **НЕ фиксированная** — перебираются конфигурации
- Типичная глубина: 2 слоя для 2D функций
- Ширина подбирается под задачу

### Число узлов сетки (grid schedule)

```
G ∈ {3, 5, 10, 20, 50, 100, 200, 500, 1000}
```

Стратегия обучения:
1. Начало на малой сетке (G=3 или G=5)
2. Обучение 200 шагов
3. Расширение сетки (`extend_grid`), сохраняя выученные кривые
4. Повтор до G=1000

Техника расширения сетки позволяет избежать локальных минимумов — сначала обучается грубое представление, потом уточняется.

### Оптимизатор

- **LBFGS** (Limited-memory Broyden-Fletcher-Goldfarb-Shanno)
- 1800 шагов на каждый интервал сетки
- Полный батч (не стохастический)

### MLP baseline

- Ширина: 5 нейронов (для малых задач) или 100 нейронов
- Глубины: `{2, 3, 4, 5, 6}`
- Функции активации: `{Tanh, ReLU, SiLU}`
- Оптимизатор: Adam, 1800 шагов

### Результат

KAN достигает RMSE ≈ 10⁻⁷ при числе параметров ~200, тогда как MLP при том же числе параметров — RMSE ≈ 10⁻².

### Проверка теоремы аппроксимации

Авторы эмпирически проверяют скейлинг-закон:

```
RMSE ∝ G^{-(k+1)}
```

При k=3 (степень сплайна по умолчанию) теория предсказывает α=4. Эксперимент показывает наклон log-log графика ≈ 4, что подтверждает теорему 2.1.

## Раздел 3.2 — Специальные функции (Special Functions)

### Задача

Аппроксимация 15 специальных функций из `scipy.special`:
- Бесселевы функции (J₀, J₁, Y₀, Y₁)
- Гамма, Бета функции
- Элементарные специальные функции

### Условия

- **3 случайных зерна** (seeds) на каждую функцию
- Фиксированная ширина: **5 нейронов**
- Глубины: `{2, 3, 4, 5, 6}`
- Тот же G-schedule, что в 3.1
- Оценка: доля задач, где RMSE < порог

### Сравнение

KAN vs MLP при идентичных условиях ширины и глубины. KAN решает значительно больше функций при меньшем числе параметров.

## Раздел 3.3 — Датасет Фейнмана (Feynman Dataset)

### Описание

Физические уравнения из базы Feynman Symbolic Regression Benchmark:
- **27 уравнений** с ≥ 2 переменными (из 120 всего в базе)
- Критерий отбора: число переменных от 2 до ~9

### Примеры уравнений

| Уравнение | Переменные |
|-----------|-----------|
| `E = qv/r` | 3 |
| `F = qvB sin(θ)` | 4 |
| `E = ½mv²` | 2 |

### Методология сравнения

Два режима KAN:
1. **Human-built KAN**: ручная конструкция на основе знания формулы (верхняя граница)
2. **Auto-pruned KAN**: автоматическое прореживание без знания формулы

Дополнительные методы в сравнении:
- MLP (тот же sweep параметров)
- EQL (Equation Learner)
- PySR (символьная регрессия эволюционным поиском)

### Оценка

- Метрика: **символьное соответствие** — восстановлена ли правильная формула
- Бинарная оценка: да/нет для каждого уравнения
- Итог: KAN восстанавливает ~17/27 уравнений в автоматическом режиме

### G-schedule

Тот же, что в 3.1. Авторы подчёркивают: без расширения сетки результаты значительно хуже.

## Раздел 3.4 — Уравнения в частных производных (PDE)

### Задача

Решение уравнения Пуассона в рамках PINN (Physics-Informed Neural Networks):

```
Δu(x,y) = f(x,y),   (x,y) ∈ [0,1]²
u|_{∂Ω} = g(x,y)
```

### Специфические гиперпараметры

| Параметр | Значение |
|---------|---------|
| Коэффициент регуляризации α | 0.01 |
| Внутренние точки (ni) | 10 000 |
| Граничные точки (nb) | 800 |
| Метрика ошибки | L² и H¹ нормы |

### Архитектура

- KAN [2, 1, 1] — 2 входа, 1 скрытый слой с 1 нейроном, 1 выход
- MLP аналогичной сложности

### Результат

KAN достигает сравнимой с MLP точности, но его решение **интерпретируемо** — можно визуализировать выученные функции активации.

## Раздел 3.5 — Непрерывное обучение (Continual Learning)

### Задача

Последовательное обучение 5 одномерных функций (пиков Гауссиана), расположенных в разных областях входного пространства.

### Условия

- Функции предъявляются **последовательно**
- После обучения на задаче i модель обучается на задаче i+1
- Оценивается забывание предыдущих задач

### Методология

- **Качественная оценка**, а не количественная
- Авторы показывают, что KAN сохраняет «локальность» — каждый узел сетки обслуживает конкретный диапазон входов
- MLP «забывает» предыдущие задачи (catastrophic forgetting)

### Объяснение

B-сплайны имеют **локальный носитель** (local support): каждый базисный сплайн ненулевой только на интервале из k+1 узлов. Поэтому обновление параметров для одного диапазона не разрушает другой. MLP с глобальными активациями (sin, ReLU) такой локальности не имеет.

## Раздел 4 — Научные приложения

### 4.1 — Специальные функции в физике

**Задача**: KAN обнаруживает символьные представления специальных функций.

**Результат**: Автоматическое нахождение известных математических отношений (например, отношение Бесселевых функций).

### 4.2 — Теория узлов (Knot Theory)

**Задача**: Классификация узлов — является ли математический узел гиперболическим?

**Условия**:

| Модель | Архитектура | Параметры | Точность |
|--------|------------|-----------|---------|
| MLP (DeepMind) | 4 слоя, ширина 300 | ~300 000 | 78% |
| KAN | [17, 1, 14] | ~200 | 81.6% |

**Архитектура KAN [17, 1, 14]**:
- 17 входных признаков
- 1 скрытый слой с 1 нейроном (узкое бутылочное горлышко)
- 14 выходных классов (или 1 с порогом)

**Вывод**: KAN не просто точнее — его активации интерпретируемы. Авторы идентифицируют, какие из 17 признаков действительно важны, и находят новую математическую гипотезу.

### 4.3 — Физика высоких энергий

**Задача**: Обнаружение фазового перехода в модели Изинга.

Авторы обучают KAN предсказывать фазу (упорядоченная/неупорядоченная), затем символизируют выученные функции.

### 4.4 — Нейронное масштабирование

**Задача**: Аппроксимация закона масштабирования (scaling law) нейронных сетей.

KAN восстанавливает известную степенную зависимость `L ∝ C^{-α}` в символьном виде.

## Скоростные характеристики

Авторы **честно указывают недостаток**:

> KANs are currently 10× slower than MLPs for forward and backward passes.

Причина: Python-цикл по узлам сетки, неоптимизированное вычисление B-сплайнов. Авторы отмечают, что это инженерная проблема, а не фундаментальная.

## Ключевые методологические принципы KAN-статьи

### 1. Никогда не фиксировать архитектуру (кроме специальных случаев)

В разделах 3.1–3.3 KAN «выигрывает» за счёт sweep по G. Честное сравнение — Pareto-кривая, а не одна точка.

### 2. Grid extension как обязательная техника

Без расширения сетки KAN существенно хуже. Это не гиперпараметр — это часть алгоритма.

### 3. Интерпретируемость как самоцель

В разделах 4.x авторы не пытаются превзойти SOTA — они демонстрируют, что KAN **открывает новые научные гипотезы**, которые MLP не может.

### 4. LBFGS, а не Adam

Для регрессионных задач LBFGS значительно превосходит Adam. Это принципиальный выбор, а не детальность реализации.

### 5. Признание слабостей

Авторы открыто указывают на 10× замедление и предлагают пути ускорения.

## Импликации для LOKAN

### Что нужно воспроизвести

1. **Pareto-sweep**: для каждой тестовой функции запустить sweep по `G ∈ {3,5,10,20,50,100}` и глубинам `{1,2,3}`, построить Pareto-кривую LOKAN vs KAN vs MLP.

2. **Grid extension**: убедиться, что `update_grid()` используется в бенчмарках — без него сравнение некорректно.

3. **LBFGS**: текущие бенчмарки `sr_staged_regression.py` используют Adam. Нужна версия с LBFGS для честного сравнения с KAN-статьёй.

4. **Символьное восстановление**: LOKAN должен демонстрировать полный пайплайн:
   - Обучение → прореживание → `auto_symbolic()` → `symbolic_formula()`
   - Показать, что формулы с умножением восстанавливаются точнее, чем у KAN

5. **Feynman benchmark**: запустить на тех же 27 уравнениях, что и KAN-статья.

### Уникальное преимущество LOKAN

KAN-статья **не тестирует** функции вида `f(x,y,z,w) = x·y + z·w` (MLR-функции). LOKAN создан именно для этого класса. Это и есть ниша для демонстрации:

| Функция | KAN (additive) | LOKAN (learnable routing) |
|---------|----------------|--------------------------|
| `x·y + z·w` | Требует 2-3 слоя | 1 слой |
| `exp(x) + sin(y)` | 1 слой | 1 слой |
| `(x₁·x₂)/(x₃+x₄)` | 3+ слоя | 2 слоя (гипотеза) |

Тест: сравнить число параметров и шагов до RMSE < 10⁻⁴ на MLR-функциях для KAN, LOKAN, MLP.
