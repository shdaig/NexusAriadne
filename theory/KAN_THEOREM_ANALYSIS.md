# Теорема 2.1 из статьи KAN и её применение к LOKAN

*Liu Z. et al. KAN: Kolmogorov-Arnold Networks, arXiv:2404.19756, 2024.*

---

## 1. Фундамент: теорема Колмогорова–Арнольда

Всё теоретическое построение KAN опирается на классический результат:

**Теорема Колмогорова–Арнольда (1957)**: Для любой непрерывной функции
f : [0,1]^n → ℝ существует точное представление вида:

```
f(x₁,...,xₙ) = Σ_{q=0}^{2n} Φ_q( Σ_{p=1}^{n} φ_{q,p}(x_p) )
```

где все φ_{q,p} : [0,1] → ℝ и Φ_q : ℝ → ℝ — непрерывные одномерные функции.

**Что даёт эта теорема архитектурно**: любую n-мерную функцию можно точно представить двухслойной сетью, если активации на рёбрах (а не в узлах) обучаемы. Именно эта идея и есть KAN: обучаемые одномерные функции на каждом ребре вместо фиксированной нелинейности в узле.

**Критическое замечание авторов KAN**: исходная теорема Колмогорова не пригодна напрямую для численного обучения, поскольку функции φ могут быть непрерывными, но негладкими (нефракталоподобными). Авторы заменяют их B-сплайнами — гладкими параметрическими кривыми — и формулируют практически применимый аналог в Теореме 2.1.

## 2. Теорема 2.1 — точная формулировка

**Теорема 2.1 (Аппроксимационная теорема KAN)**

Пусть f имеет представление Колмогорова–Арнольда и все его компонентные функции φ_{q,p} и Φ_q принадлежат классу C^{k+1} (т. е. непрерывно дифференцируемы (k+1) раз). Тогда существует KAN с B-сплайнами порядка k и сеткой из G интервалов, для которого выполняется:

```
‖KAN(x) − f(x)‖_∞  ≤  C · G^{−(k+1)}
```

где постоянная C зависит от f и k, но **не зависит от размерности n**.

Число параметров такого KAN:

```
Θ = O(N² · p · G)
```

где N — ширина (число нейронов в слое), p — число слоёв.

### Что значит каждое слагаемое

| Символ | Смысл | Как влияет на ошибку |
|---|---|---|
| G | число интервалов сетки | ошибка ∝ G^{−(k+1)}, чем больше G, тем лучше |
| k | порядок B-сплайна | скорость сходимости растёт с k |
| C | константа гладкости f | зависит от (k+1)-й производной φ, не от n |
| n | размерность входа | **не входит в показатель** — нет проклятия размерности |

## 3. Ключевые инструменты доказательства

### 3.1 Теория аппроксимации B-сплайнами

Центральный математический факт, на котором стоит теорема:

**Лемма (сплайновая аппроксимация)**: Для любой функции φ ∈ C^{k+1}([a, b]) существует B-сплайн S_G степени k с G равномерными узлами, такой что:

```
‖φ − S_G‖_∞  ≤  C_φ · (b−a)^{k+1} / G^{k+1}
```

где C_φ = ‖φ^{(k+1)}‖_∞ / (k+1)!

**Физический смысл**: чем мельче разбивка сетки (больше G) и чем выше степень сплайна k, тем точнее аппроксимация. Ошибка убывает как полином от 1/G — это "хорошая" скорость сходимости.

### 3.2 Распространение ошибки через композицию

Когда мы заменяем каждую φ_{q,p} на сплайн S^{q,p}_G с ошибкой ε, суммарная ошибка в итоговой функции оценивается через константы Липшица внешних функций Φ_q:

```
‖f − KAN_f‖_∞ ≤ Σ_q L_q · (Σ_p ε_{q,p})
```

где L_q = Lip(Φ_q) — константа Липшица для q-й внешней функции.

Поскольку все Φ_q тоже аппроксимируются сплайнами с ошибкой O(G^{−(k+1)}), итоговая ошибка остаётся O(G^{−(k+1)}) — показатель не ухудшается.

### 3.3 Схема доказательства (пошагово)

```
1. Существование разложения
   f(x₁,...,xₙ) = Σ_q Φ_q(Σ_p φ_{q,p}(x_p))   [теорема К-А]

2. Аппроксимация внутренних функций
   φ_{q,p} ≈ S^{q,p}_G,   ‖φ−S‖_∞ ≤ ε₁ = C₁ · G^{−(k+1)}

3. Аппроксимация внешних функций
   Φ_q ≈ T^q_G,            ‖Φ−T‖_∞ ≤ ε₂ = C₂ · G^{−(k+1)}

4. Комбинирование через константы Липшица
   ‖f − KAN_f‖_∞ ≤ (2n+1) · max_q(L_q) · (n·ε₁ + ε₂)
                 = C · G^{−(k+1)}

5. Подсчёт параметров
   Параметров сплайна для одного ребра = k + G
   Всего рёбер в 2-слойном KAN = n·(2n+1) + (2n+1)·1 = O(n²)
   Итого параметров = O(n² · (k + G))
```

### 3.4 Почему нет проклятия размерности

В классическом многомерном случае для аппроксимации функции f : [0,1]^n с точностью ε нужно O(ε^{−n/(k+1)}) параметров — экспоненциально в n.

В KAN благодаря декомпозиции К-А задача сводится к аппроксимации **одномерных** функций. Для каждой одномерной φ нужно O(ε^{−1/(k+1)}) параметров. Таких функций O(n²), поэтому суммарно — O(n² · ε^{−1/(k+1)}), что растёт как полином в n, а не экспонента.

**Визуально**:
```
MLP:  параметров ∼ ε^{−n/(k+1)}   (экспонента от n)
KAN:  параметров ∼ n² · ε^{−1/(k+1)}  (полином от n)
```

## 4. Практические следствия теоремы 2.1 для KAN

### Следствие 1: Grid extension

Поскольку ошибка убывает как G^{−(k+1)}, можно начать обучение с грубой сеткой (маленькое G — быстрое обучение, нет переобучения), затем сгустить сетку — и получить более точный результат **без переобучения с нуля**. Именно так работает `update_grid_from_samples` в LOKAN.

### Следствие 2: Выбор k

При k=3 (кубический сплайн, значение по умолчанию) ошибка убывает как G^{−4}. Повышение до k=5 даёт G^{−6}, но при этом каждый сплайн требует больше параметров. Оптимальный k зависит от гладкости целевой функции.

### Следствие 3: Scaling law

Теорема предсказывает зависимость RMSE ∝ G^{−(k+1)} при фиксированном k. Это должно быть видно на log-log графике RMSE vs G (или vs числа параметров) — прямая с наклоном −(k+1). Такой график — стандартное "scaling law" figure в статье KAN.

## 5. Применение к LOKAN: расширение теоремы

### 5.1 LOKAN содержит KAN как частный случай

**Утверждение 1 (LOKAN ⊇ KAN)**:
LOKAN со слоем, у которого G=1 (только аддитивная группа, мультипликативных нет), точно совпадает с KAN-слоем.

*Доказательство*: При G=1 тензор логитов имеет форму (in_dim, out_dim, 1), softmax по единственному слоту = 1. Тогда p_{i,o,1} = 1 для всех i, o — все входы маршрутизируются в аддитивную группу. Выход:
```
sum_o = Σ_i p_{i,o,1} · ỹ_{i,o} = Σ_i ỹ_{i,o}
```
что в точности совпадает со стандартной KAN-агрегацией. □

**Следствие**: Теорема 2.1 применима к LOKAN в полном объёме — LOKAN не хуже KAN теоретически.

### 5.2 LOKAN расширяет класс представимых функций

KAN в своей стандартной форме агрегирует входы только суммированием в каждом узле. Произведение в KAN требует специального обхода: либо через логарифм (log → сумма → exp), что требует дополнительного слоя и предполагает положительность аргументов, либо через явную инициализацию мультипликативных узлов (KAN 2.0 / MultKAN).

LOKAN устраняет это ограничение на уровне агрегации одного слоя.

**Определение**: Назовём функцию *мультилинейно разложимой* (МЛР-функцией), если она представима в виде:

```
f(x) = Σ_{g=1}^{K} ∏_{i ∈ S_g} φ_{i,g}(x_i)  +  Σ_{i ∈ S_add} ψ_i(x_i)
```

где {S_g} — непересекающиеся подмножества индексов входов, φ_{i,g} и ψ_i — одномерные функции.

Примеры МЛР-функций: `x₀·x₁ + x₂·x₃`, `x₀/x₁ + x₂/x₃`, `sin(x₀)·cos(x₁)`.

### 5.3 Теорема об аппроксимации для LOKAN (формулировка)

**Предложение (LOKAN Approximation Theorem)**:

Пусть f — МЛР-функция с K мультипликативными группами, и каждая компонентная функция φ_{i,g} ∈ C^{k+1}. Тогда существует однослойный LOKAN с B-сплайнами порядка k, сеткой G и K мультипликативными группами (K ≤ G−1), для которого:

```
‖LOKAN(x) − f(x)‖_∞  ≤  C · G^{−(k+1)}
```

причём C не зависит от размерности входа n.

*Структура доказательства*:

**Шаг 1 — конструкция**: Для каждой мультипликативной группы g зададим логиты так, что softmax даёт:
```
p_{i,o,g} = 1,  если i ∈ S_g,
p_{i,o,g} = 0,  иначе.
```
(В мягкой версии: p_{i,o,g} = 1−δ для малого δ > 0.)

**Шаг 2 — вычисление term**: При p_{i,o,g} = 1:
```
term_{i,o,g} = 1 − 1 + 1 · ỹ_{i,o} = ỹ_{i,o}
```
При p_{i,o,g} = 0:
```
term_{i,o,g} = 1 − 0 + 0 · ỹ_{i,o} = 1  (нейтральный элемент произведения)
```

**Шаг 3 — вычисление prod**: 
```
prod_{o,g} = ∏_{i=1}^{d_in} term_{i,o,g} = ∏_{i ∈ S_g} ỹ_{i,o}
```

**Шаг 4 — B-сплайновая аппроксимация**:
Каждая ỹ_{i,o} аппроксимирует φ_{i,g}(x_i) с ошибкой ε_i ≤ C_i · G^{−(k+1)}.

**Шаг 5 — оценка ошибки произведения**:
Используя неравенство для погрешности произведения приближений:
```
|∏ ỹ_{i,g} − ∏ φ_{i,g}| ≤ Σ_{i ∈ S_g} ε_i · ∏_{j≠i} ‖φ_{j,g}‖_∞
                          ≤ |S_g| · max_i(ε_i) · M^{|S_g|−1}
```
где M = sup |φ_{i,g}|. Это по-прежнему O(G^{−(k+1)}).

**Шаг 6 — суммирование по группам**:
Суммирование K слагаемых умножает ошибку на K = O(n), что входит в константу C.

Итог: ‖LOKAN(x) − f(x)‖_∞ ≤ C · G^{−(k+1)}. □

### 5.4 Преимущество по глубине: LOKAN vs KAN

Ключевое следствие предложения — **глубинная эффективность**:

| Задача | KAN: минимальная глубина | LOKAN: минимальная глубина |
|---|---|---|
| f = Σ φ_i(x_i) | 1 слой | 1 слой |
| f = ∏ φ_i(x_i) | 2 слоя | **1 слой** |
| f = Σ_g ∏_{i∈S_g} φ_i(x_i) | 2 слоя | **1 слой** |
| f = (x₀/x₁)(x₂+x₃) | 3 слоя | **2 слоя** |

Двухслойная KAN-сеть через логарифм для произведения: `f = φ₁(x₀)·φ₂(x₁)` требует: слой 1 вычисляет `log φ_i(x_i)`, слой 2 суммирует и применяет `exp`. Это работает только при положительных φ_i и требует дополнительного слоя.

LOKAN делает то же самое прямо в одном слое и без ограничений на знак, через формулу `term_{i,g} = 1 − p + p·ỹ`.

### 5.5 Ограничение класса МЛР: что LOKAN не покрывает

Теорема Колмогорова–Арнольда гарантирует, что любую непрерывную функцию можно представить двухслойной стандартной KAN. Аналогичная теорема для LOKAN должна утверждать большее: некоторые функции, требующие 2 слоёв в KAN, достигаются 1 слоем в LOKAN.

Однако не любая функция является МЛР-функцией (например, `sin(x₀ + x₁·x₂)` требует вложенной структуры). Для таких функций LOKAN тоже нужен многослойным, и тогда Теорема 2.1 применяется по рекурсии — аналогично KAN.

## 6. Что нужно сделать для публикации

### Минимальный теоретический вклад (для статьи уровня arXiv/ICLR)

1. **Оформить Утверждение 1** (LOKAN ⊇ KAN) как лемму с полным доказательством — это тривиально, но важно для строгости.

2. **Оформить Предложение** (аппроксимационная теорема LOKAN) с полным доказательством. Шаги 1–6 выше дают его скелет; нужно аккуратно записать оценку в Шаге 5.

3. **Добавить следствие о глубине**: однослойный LOKAN аппроксимирует МЛР-функции с той же скоростью O(G^{−(k+1)}), что и двухслойный KAN, при вдвое меньшем числе параметров.

### Экспериментальная проверка теоремы

Scaling law plot (обязателен для статьи уровня KAN):
- Зафиксировать k=3, варьировать G ∈ {3, 5, 10, 20, 50}
- Измерить RMSE на f = x₀·x₁ (чистое произведение) и f = x₀·x₁ + x₂·x₃
- Нанести на log-log график — наклон должен быть ≈ −4 = −(k+1)
- Сравнить LOKAN и KAN: LOKAN должен достигать той же точности при вдвое меньшем G (за счёт однослойного представления)

### Чего не хватает: расширение теории на произвольные функции

Текущая теорема покрывает МЛР-класс. Для полного аналога теоремы К-А нужна *двухслойная LOKAN-теорема*: "любую непрерывную функцию можно представить двухслойным LOKAN". Это требует доказательства, что стандартная сумма произведений (канонический полином) плотна в C([0,1]^n), что следует из теоремы Вейерштрасса для полиномов. Это было бы сильным теоретическим результатом, но выходит за рамки минимально необходимого для первой публикации.

## 7. Краткое резюме

```
Теорема К-А            →  KAN архитектура (learnable activations на рёбрах)
                            ↓
Теорема 2.1 (KAN)       →  ошибка ≤ C·G^{-(k+1)},  нет проклятия размерности
                            ↓
Инструмент: B-сплайны   →  каждая φ ≈ S_G с ошибкой O(G^{-(k+1)})
                            ↓
LOKAN ⊇ KAN             →  Теорема 2.1 применима к LOKAN напрямую
                            ↓
LOKAN расширяет KAN     →  МЛР-функции однослойно ≡ двухслойный KAN
                            ↓
Предложение (LOKAN)     →  та же скорость O(G^{-(k+1)}), меньшая глубина
```
